# Books & Databases

A fast, interactive, and responsive reader with dark/AMOLED/light themes, offline search, and client-side encryption.

## Features
- **Mobile-First UI**: Authentic interface with date separators and smooth scrolling.
- **Client-Side Encryption**: Secure hardware-grade access.
- **Starred Messages**: Save and browse bookmarked items.
- **3 Themes**: Dark Mode, AMOLED Pure Black, and Classic Light Theme.
- **Instant Search & Date Jump**: Fast in-document text search and calendar navigation.
- **Zero Dependencies**: Pure HTML/CSS/JS that runs 100% offline.
